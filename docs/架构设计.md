# GraphMind 系统架构设计文档

## 1. 架构概述

GraphMind 采用前后端分离的微服务架构，整体分为前端展示层、后端服务层和数据存储层三个主要层次。系统通过统一的接口层与多种图数据库进行交互，实现对不同图数据库的抽象和支持。

## 2. 总体架构图

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Frontend      │    │   Backend       │    │   Graph DBs     │
│   Vue.js +      │◄──►│   Spring Boot   │◄──►│   JanusGraph    │
│   Vite          │    │   Admin Server  │    │   NebulaGraph   │
│                 │    │                 │    │   Neo4j         │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

## 3. 技术栈

### 3.1 后端技术栈
- 核心框架：Spring Boot 3.x
- 安全框架：Spring Security（JWT 无状态认证）
- 数据访问：MyBatis Plus 3.5.x
- 图数据库客户端：
  - JanusGraph：gremlin-driver
  - NebulaGraph：nebula-java
  - Neo4j：neo4j-java-driver

### 3.2 前端技术栈
- 框架：Vue.js 3.x
- 构建工具：Vite
- UI 组件库：Element Plus
- 图形可视化：D3.js、ECharts
- 状态管理：Pinia
- 路由：Vue Router 4

### 3.3 其他组件
- 日志：Logback + SLF4J

## 6. 关键设计决策

### 6.1 图数据库抽象层设计
为了支持多种图数据库，我们设计了统一的图操作接口，并通过适配器模式实现对不同图数据库的支持。

```
GraphOperations Interface
├── JanusGraphOperations
├── NebulaGraphOperations
└── Neo4jOperations
```

### 6.2 配置管理
采用工厂模式管理不同图数据库的连接配置，支持动态切换图数据库类型。

### 6.3 安全设计
- 使用 JWT 实现无状态认证
- 支持在开发环境中关闭认证（`auth.enable: false`）
- CORS 跨域配置
