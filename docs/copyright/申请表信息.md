### 开发目的
面向企业多源异构图数据库的统一管理需求，针对 Neo4j、Nebula Graph、JanusGraph 等主流图数据库各自采用不同查询语言（Cypher/nGQL/Gremlin）和原生管理工具的现状，构建一套基于适配器模式的统一 Web 可视化管理平台。用户无需学习和切换多套图数据库专用工具，即可在一个平台内完成数据库连接配置、图 Schema 建模、顶点与边的数据管理、图查询执行、图结构可视化探索以及图数据统计与分析等全流程操作，显著降低图数据库的使用门槛与运维成本，提升知识图谱项目的开发与交付效率。
为多源异构图数据库提供统一的管理平台，降低图数据库的使用门槛与运维成本

### 软件的主要功能：
1、图数据库连接管理：支持 Neo4j、Nebula Graph、JanusGraph 等多种图数据库的连接配置新增、编辑、删除与连通性测试，可管理连接地址、端口、认证凭据等参数，提供连接状态实时检测与异常提示。

2、图实例管理：基于已配置的数据库连接，支持图实例（Database/Space/Graph）的创建、删除与查看，管理图的基本元数据（名称、所属连接、数据库类型等），提供图列表的分页查询与关键词检索功能。

3、图建模（Schema 设计）：提供顶点类型和边类型的可视化定义功能，支持为点边配置属性字段（名称、数据类型、默认值、是否必填等），支持列表视图与 D3.js 图形化 Schema 视图双模式展示，支持 Schema 的 JSON 格式导入导出与一键发布至目标图数据库，支持增量变更与自动反向发现已有 Schema。

4、图数据管理：支持顶点和边的逐条新增、编辑、删除，支持 CSV 文件批量导入顶点与边数据，内置 UTF-8 / GBK 编码自动检测，导入失败时自动降级为逐条插入并生成错误追踪报告，支持按属性条件筛选与检索图数据记录。

5、图查询与可视化：内置 Monaco Editor 代码编辑器，支持 Cypher、nGQL、Gremlin 多种图查询语言的语法高亮与执行；基于 D3.js 力导向图渲染查询结果，支持力导向布局与层次布局切换、节点拖拽与缩放平移、邻居节点展开与收起、选中顶点/边详情浮层展示，支持将可视化结果导出为 PNG、SVG 或 JSON 格式。

6、图分析：支持基于图结构的路径查找（最短路径与全路径），支持指定节点的多层级邻居遍历展开，结合图查询语言可实现子图匹配、关联关系挖掘等分析操作。

7、图数据统计：提供图级别汇总统计信息，包括顶点与边的总量、各标签（Label/Tag）的数量分布，以图表形式直观展示图数据库的数据规模与结构组成。
### 技术特点：
采用模块化分层架构，通过统一图数据库操作接口与策略模式，实现各图数据库独立模块的解耦。运用工厂模式动态适配数据源，结合SPI扩展机制，可灵活热插拔地新增图数据库类型，保证了系统的高度可扩展性。
